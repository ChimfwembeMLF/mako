# Quickstart: Trinolux SMS

1. In the Trinolux console, create an API key with the SendSMS scope and copy it. It's shown only once.
2. Note an approved Sender ID, exactly as written. For testing, use `Trinolux` if your account shows it.
3. In Mako, open Platform Backoffice → SMS, and save the key and Sender ID.
4. Send a test to your own Zambian number.
5. Confirm the phone receives it. Mako reports only that Trinolux accepted the message.

Each test uses real SMS balance. If a key is exposed, revoke it in Trinolux immediately.
