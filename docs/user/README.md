# Mako user guides

Plain-language help for people who create and publish content in Mako.

These guides are for marketers, content creators, and team leads — not for developers.

## What Mako helps you do

Mako is where you:

1. Describe your brand once (Brand Brain)
2. Connect your social accounts
3. Write or generate posts
4. Schedule or publish them
5. See how they performed and reply to comments

It is **not** a website builder. You use it to run social and marketing content from one place.
